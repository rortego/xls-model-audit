# Excel model audit

A checker for Excel models that were generated by a script or by an AI agent. It runs before the file goes to anyone.

## Why

I build financial models from Python, with AI agents writing part of the code. A generated workbook can open fine, look right and still be wrong: a formula that reads an empty cell, a note that Excel shows as `#NAME?`, a file that Excel has to "repair". Each check below comes from a defect found while auditing a real model.

## What it checks

| Check | What goes wrong |
|---|---|
| Recalculation outside Excel | Every formula is recalculated with the `formulas` engine. Any `#REF!`, `#DIV/0!` or `#NAME?` is an error. |
| Text stored as a formula | A note that starts with `= ` is saved as a formula and shows `#NAME?`. |
| Overlapping merges | Two merged ranges that overlap make Excel repair the file on opening. |
| Values lost in merges | Merging wipes every cell except the top-left one. A formula that points to a wiped cell reads zero. |
| Typed number in a formula row | One hard-coded value in the middle of a row of formulas. Reported as a warning. |
| Broken number formats | An unquoted literal in a number format makes Excel report "a problem with some content". |

## Run it

```
pip install -r requirements.txt
python make_samples.py
python audit.py sample_clean.xlsx sample_broken.xlsx
```

```
sample_clean.xlsx: 63 cells recalculated · 0 error(s) · 0 warning(s)
sample_broken.xlsx: 68 cells recalculated · 6 error(s) · 1 warning(s)
  error   PNL!A11                recalculates to #REF!
  error   PNL!H9                 recalculates to #DIV/0!
  error   PnL!A11                text stored as a formula: '= margin after fixed costs'
  error   PnL!A1:I1              merged range overlaps A1:H1
  error   PnL!B8                 points to Inputs!C3, a cell wiped by a merge
  error   styles                 number format with unquoted '–': #,##0;(#,##0);–
  warning PnL!D4                 typed value -70 inside a row of 6 formulas
```

`make_samples.py` builds the two workbooks: the same six-month P&L, once clean and once with the six defects planted. The exit code is 1 when there is any error, so the audit can gate a build.

## Limits

It checks the mechanics of the file, not the logic of the model. A model can pass every check and still rest on a wrong assumption; for that I write a second, independent calculation of the key figures and compare. The `formulas` engine does not support every Excel function, so a finding in an unusual formula should be confirmed in Excel.
